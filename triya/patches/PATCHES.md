# Upstream files touched by the Triya CAD 3D overlay

Base: SolidCraft v0.22.0, commit `0537623` (`git diff v0.22.0` → `0001-seams.patch`;
`Cargo.lock` separately in `0002-cargo-lock.patch`). Every seam in a file whose syntax has
comments carries `// Modified by Triya CAD 3D: <why>`. JSON has no comment syntax, so the three
catalog lines are recorded only here.

Refresh both patches after changing a seam: `bash triya/ci/refresh-seam-patches.sh` (Triya CI runs it
with `--check`). Re-apply on a new upstream release: `git apply triya/patches/0001-seams.patch` from the repo
root, then `cargo update --workspace` (or let cargo regenerate the lock) instead of `0002`.

## Not touched, by design

- No design-format change (`crates/doc/src/format/pending/`): the vessel JSON lives in
  `Document::metadata` under `in.openengtools.triya.vessel`, which upstream reserves for other
  tools' data.
- No upstream icon or artwork files: the commands use upstream's code-drawn icons (`cylinder`, `params`,
  `compute`, `measure`); the web app's icons are exports of Triya's own code-drawn mark
  (`triya/crates/triya-brand/src/mark.rs`), attributed in row 14.
- `apps/solidcraft` (desktop) is not copied: see `triya/README.md`.
