This project ships Triya CAD 3D — a rebranded fork of SolidCraft v0.14.0 with an overlay in `triya/` — to an installable PWA beta with the parametric pressure-vessel module and GA drawing export by 8 Nov 2026. Repository: <you>/triya-cad-3d. The plan is `triya/PLAN.md`; the live state is `triya/PROGRESS.md`; the rules are the root `CLAUDE.md` (upstream's) plus `triya/CLAUDE.md` and `triya/AGENTS.md`, which every thread must read first.

- Branch from `main`; name branches `triya/<phase>-<topic>`; one PLAN task per PR; use the PR template in `triya/AGENTS.md` §6; squash-merge only when `CI` and `Triya CI` are green. Never push to `main` directly, never force-push, never merge `upstream/main` before the tag `triya-v0.1.0-beta` exists.
- Edit upstream files only at the seams in `triya/patches/PATCHES.md` (each marked "Modified by Triya CAD 3D"); everything else goes under `triya/`. `bash triya/ci/check-patch-whitelist.sh v0.14.0` must pass before every push.
- Geometry only through SolidCraft commands (never `truck`/`solidcraft-kernel`); no `FeatureKind` or format changes; no fillets on curved edges in the beta; validate every boolean by volume and fall back to a separate body with a flag.
- Builds: `export CARGO_TARGET_DIR=/root/target`. While working, run `cargo check` and `cargo test -p triya-brand -p triya-stdlib -p triya-vessel -p triya-drawing -p triya-ui`; run the full `cargo xtask ci` once before opening the PR and rely on GitHub Actions for the rest. Keep one thread per phase so the build cache survives; subagents only for tasks marked ∥, each on disjoint crates, and they add files — never replace existing folders.
- Tests first: the acceptance test named in PLAN.md exists and fails before the implementation. For anything a user sees, produce a snapshot PNG and look at it; commit it under `triya/docs/img/` with an ATTRIBUTION row.
- Licence hygiene: never read, copy or link GPL/LGPL/AGPL code (OpenCASCADE, FreeCAD, CadQuery/OCP, SolveSpace, LibreCAD, QCAD); never extract data from PV Elite, COMPRESS, AutoPIPE or any commercial CAD; never commit EIL or other proprietary standard tables; SPDX headers on every new file; ATTRIBUTION rows for every data table and asset. Only crates.io dependencies with permissive licences.
- Before calling work done: update `triya/PROGRESS.md` (Done/Decisions/Measurements/Log), paste the gate summary lines in the final message, and list any `Owner decisions` you added.
- Ask me first (write it in PROGRESS.md "Owner decisions" and continue with other work): anything irreversible outside the repo, any upstream edit beyond the seams, dependency licences outside the permissive list, changes to beta scope or date, product-defining UX defaults with no public reference, anything involving money, accounts or credentials.
- Tags are created with `gh api repos/<you>/triya-cad-3d/git/refs -f ref=refs/tags/<tag> -f sha=<sha>` (the GitHub proxy rejects `git push --tags`).
