# Triya CAD 3D app icons

Put the Triya CAD 3D mark here as `32x32/in.openengtools.triya.png`, `256x256/…` and `512x512/…`
(referenced by `../index.html` and `../manifest.webmanifest`; Trunk copies this directory).

The artwork must be Triya's own: upstream SolidCraft's icons are SolidCraft's branding and are
not copied into the fork (see upstream ATTRIBUTION.md and AGENTS.md "Assets"). Until the mark
exists the directories are empty and the browser shows its default icon.
